# MP-2026-TermProject

**마이크로프로세서응용 텀프로젝트 (2026)**  
**프로젝트:** 다중 센서 기반 실시간 이벤트 감지 및 데이터 블랙박스 시스템  
**플랫폼:** DE1-SoC · C

## 프로젝트 목표

진동·소음·조도 데이터를 주기적으로 수집하고, 이상 이벤트를 감지·분류하여 **이벤트 발생 전후 데이터를 기록**한다. LED/HEX 및 VGA 등으로 현재 상태와 기록을 확인할 수 있는 시스템을 목표로 한다.

> 현재 문서는 **설계안**이다. ADC·Audio·VGA 접근 방식과 실제 부품 연결, 샘플링 주기 등은 보드 환경 확인 후 확정한다.

## 주요 기능

- F1. 실시간 다중 센서 데이터 측정
- F2. 이상 이벤트 자동 감지
- F3. 이벤트 발생 전후 데이터 자동 저장 (예정: 전 5초·후 5초)
- F4. 다중 센서 기반 이벤트 분류
- F5. 실시간 모니터링 및 데이터 시각화
- F6. 이벤트 기록 조회 및 사용자 설정
- F7. 이벤트 알림 및 경고 제어
- F8. 시스템 모드 및 오류 처리
