### 안건 4. 개발 역할 분담

**분업 제안: Sensor & Storage / Event & UI**

#### 윤아 — Sensor & Storage

| 모듈 | 담당 기능 | 주요 파일 |
|---|---|---|
| Sensor | 진동·조도 ADC 입력, Audio-in, 필터링 | `vibration.c`, `light.c`, `sound.c`, `sensor_filter.c` |
| System | Timer 및 Interrupt, 시스템 시간 관리 | `timer.c`, `interrupt.c` |
| Storage | Ring Buffer, 이벤트 전후 데이터 기록 | `ring_buffer.c`, `event_record.c` |

**독립 개발 목표**
- 실제 센서 데이터를 `SensorSample`로 생성
- 일정한 주기로 데이터 측정 및 저장
- Mock 이벤트를 이용한 이벤트 전후 데이터 기록 검증

#### 연경 — Event & UI

| 모듈 | 담당 기능 | 주요 파일 |
|---|---|---|
| Event | 이벤트 감지·분류, 복합 이벤트 판단 | `event_detector.c`, `event_classifier.c` |
| Display | VGA, LED·HEX, Audio-out 경고 | `vga.c`, `led_hex.c`, `alarm.c` |
| Input/UI | KEY·SW, 모드 전환, 기록 조회 | `key_switch.c`, `system_state.c` |

**독립 개발 목표**
- Mock 센서 데이터 기반 이벤트 감지·분류
- 이벤트 결과에 따른 화면·LED·경고 출력
- 사용자 입력에 따른 모드 및 설정 변경

#### 공동 담당

- 공통 자료구조 및 함수 API 정의
- 하드웨어 초기화 및 인터럽트 처리 규칙 합의
- `main.c` 통합
- 모듈 간 데이터 연결 및 전체 시스템 테스트
- 최종 데모 및 결과보고서 작성

※ 담당자와 구체적인 파일 소유권은 최종 합의 필요.

## 5. 발생한 문제 및 해결 방안

현재 확인된 구현 오류는 없으며, 다음 사항에 대한 사전 검증이 필요함.

- **ADC 및 Audio-in/out:** 실제 DE1-SoC 환경에서 접근 및 입출력 확인
- **Interrupt:** Timer와 KEY의 IRQ 처리 및 초기화 방식 확인
- **데이터 통합:** 센서별 측정 주기가 다를 경우 데이터 동기화 방식 정의
- **Ring Buffer:** 이벤트 전후 5초 기록을 위한 메모리 용량 및 보존 정책 결정
- **모듈 통합:** 인터페이스 변경으로 인한 충돌을 방지하기 위해 공통 헤더 우선 확정
