## Documentation Guidelines

각 회의록에는 다음 내용을 포함합니다.

1. **Meeting Info** — 날짜, 참석자, 회의 목적
2. **Discussion** — 주요 논의 사항
3. **Decisions** — 최종 결정 사항
4. **Action Items** — 담당자별 작업 및 기한
5. **Issues** — 발생한 문제 및 해결 방향
6. **Next Meeting** — 다음 회의 안건

## File Naming Convention

회의록 파일명은 `YYYY-MM-DD.md` 형식을 사용
