## 2. 논의 내용

### 안건 1. 센서 이벤트 감지 및 임계값 조정

- SHOCK·SOUND·LIGHT 단일 이벤트의 실제 보드 동작 결과 공유
- 조도 센서에서 LIGHT 이벤트가 반복 발생하는 문제 확인
- 조도 변화량 임계값 조정 및 재감지 잠금 해제 조건 검토
- 초기 5초 센서 평균값을 Baseline으로 사용하는 방식 논의
- 초기 측정 구간의 환경 변화가 Baseline에 영향을 줄 수 있는 문제 검토
- 센서별 정상 변동 범위와 이벤트 감지 임계값 추가 조정 필요성 확인

### 안건 2. 복합 이벤트 감지 문제

- 현재 SHOCK·SOUND·LIGHT 단일 이벤트는 발생하지만 복합 이벤트는 감지되지 않음
- 공통 이벤트 Flags는 비트 OR 연산으로 복합 이벤트 표현이 가능하도록 정의되어 있음
- 현재 감지 함수에서 서로 다른 센서의 이벤트가 동일한 시점에 확정되어야 복합 Flags가 반환될 수 있는 구조 확인
- 센서별 감지 시점과 쿨다운 및 재감지 조건이 서로 달라 복합 이벤트 감지에 영향을 줄 가능성 논의
- 복합 이벤트를 어떤 시간 범위에서 하나의 이벤트로 판단할지 추가 설계 필요

**추후 검토 사항**

- 복합 이벤트 판정 시간 범위 설정
- 일정 시간 내 발생한 서로 다른 센서 이벤트를 통합하는 방식 검토
- 복합 이벤트 발생 시 기존 Event Record 교체 정책과의 관계 확인
- 복합 이벤트의 Event History 및 LED/HEX 표시 확인

### 안건 3. Ring Buffer 및 Event Record 테스트

- Ring Buffer에 최근 센서 데이터 500개 유지
- 이벤트 발생 이전 500개와 이후 500개를 Event Record에 저장
- 새로운 이벤트가 발생하면 가장 최근 이벤트 기준으로 Record 교체
- 실제 보드에서 `Pre:500 | Post:500 | Total:1000` 저장 완료 확인
- JTAG UART로 BEFORE/AFTER 대표 센서 데이터 출력
- 전체 1,000개 샘플의 시간 간격 및 연속성은 추가 검증 필요

### 안건 4. Event History 및 콘솔 출력

- 이벤트 발생 시간과 Flags를 최대 10건까지 저장
- 새 이벤트 발생 즉시 History 저장 개수 출력
- 모니터링 시작 후 10초마다 History 자동 출력
- History는 오래된 이벤트부터 최근 이벤트 순서로 표시
- 단일 이벤트의 History 저장 및 순환 관리 확인
- 복합 이벤트 History 저장은 복합 감지 문제 해결 후 테스트 필요

### 안건 5. VGA 출력 기능 추가

- JTAG UART 이외에 VGA를 통한 센서 및 이벤트 데이터 표시 기능 추가 결정
- 실시간 센서 데이터 모니터링 화면 구현
- 최신 Event Record 데이터 표시
- 최근 Event History 최대 10건 표시

**역할 분담**

- 연경: VGA 센서 데이터·Event Record·Event History 표시 기능 구현
- 윤아: 기존 센서 수집 및 데이터 저장 모듈 점검, 연동 지원
- 공동: VGA 및 기존 시스템 통합 테스트

### 안건 6. 미검증 기능 및 추가 테스트

- 실제 스피커 Audio-out 출력 테스트는 아직 진행하지 않음
- JTAG UART 일부 문자열 누락 현상 확인
- 복합 이벤트 감지는 현재 미동작 상태
- VGA 구현 이후 전체 시스템 통합 테스트 필요

## 5. 발생한 문제 및 해결 방안

**문제 1. 조도 센서 이벤트 반복 발생**

- **원인:** 낮은 조도 변화량 임계값 및 재감지 잠금 해제 조건
- **해결 방안:** 임계값 조정 및 안정 시간 기반 재감지 로직 적용
- **현재 상태:** 반복 감지 감소 확인, 추가 보정 필요

**문제 2. 복합 이벤트 감지 실패**

- **현상:** SHOCK·SOUND·LIGHT 각각의 이벤트는 발생하지만 복합 이벤트 Flags는 감지되지 않음
- **원인 가능성:** 센서별 이벤트 확정 시점이 일치하지 않으며, 현재 Event Detector는 같은 감지 호출에서 발생한 Flags를 조합하는 구조
- **해결 방안:** 일정 시간 내 발생한 센서별 이벤트를 복합 이벤트로 처리하는 방식 검토 및 구현
- **현재 상태:** 미해결, 우선 개선 필요

**문제 3. Event Record 수집 중 신규 이벤트 발생**

- **원인:** 이후 500개 데이터 수집이 완료되기 전에 새로운 이벤트 발생
- **해결 방안:** 최신 이벤트 기준으로 Record를 교체하는 정책 유지
- **현재 상태:** Record 교체 및 총 1,000개 저장 완료 동작 확인

**문제 4. JTAG UART 출력 누락**

- **원인 추정:** 출력 버퍼 전송 공간 부족 및 타임아웃 처리
- **해결 방안:** 대표 샘플만 출력하고 UART 전송 방식 추가 개선
- **현재 상태:** 일부 누락 현상 지속

**문제 5. 초기 Baseline 변동**

- **원인 가능성:** 초기 측정 구간의 센서값 변화 및 외부 자극
- **해결 방안:** 5초 평균값 사용 및 센서별 기준값 추가 보정
- **현재 상태:** 추가 테스트 필요

**문제 6. Audio-out 실제 동작 미검증**

- **원인:** 실제 스피커 연결 및 출력 테스트 미진행
- **해결 방안:** Audio-out 하드웨어 출력 및 경고음 동작 검증
- **현재 상태:** 미검증
