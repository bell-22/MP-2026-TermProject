## Documentation Guidelines

개발 로그에는 다음 내용을 기록합니다.

1. **Development Info** — 작성자, 작업 날짜, 담당 모듈
2. **Objectives** — 작업 목표
3. **Implementation** — 구현 기능 및 수정한 파일
4. **Testing** — 테스트 항목 및 실제 결과
5. **Issues & Solutions** — 발생한 오류와 해결 과정
6. **Next Tasks** — 다음 작업 계획
7. **References** — 관련 Commit, Issue, Pull Request

## File Naming Convention

개발 로그 파일명은 `YYYY-MM-DD.md` 형식을 사용

## Status Guidelines

- **TODO** — 작업 예정
- **IN PROGRESS** — 개발 진행 중
- **DONE** — 구현 및 검증 완료
- **BLOCKED** — 문제 발생으로 작업 중단

테스트가 완료되지 않은 기능은 구현 여부와 별개로 검증 상태를 기록합니다.
