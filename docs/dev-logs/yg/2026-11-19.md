## 3. 구현 및 작업 내용

### 작업 1. 조도 센서 이벤트 감지 임계값 조정

**작업 대상**

- `include/system_config.h`
- `src/event/event_detector.c`

**작업 내용**

기존 조도 센서 감지 설정을 검토하고, 실제 센서 입력 변화에 적합하도록 이벤트 판정 임계값을 수정하였다.

조도 센서는 초기 평균값과 현재 측정값의 절댓값 차이를 계산하여 이벤트를 판단한다.

**변경된 설정값**

| 항목 | 기존 | 변경 |
|---|---|---|
| 조도 변화량 임계값 | 50 | 150 |
| 재감지 해제 변화량 | - | 75 |
| 재감지 해제 확인 시간 | - | 300ms |
| 이벤트 확정 | 연속 2회 | 유지 |
| 이벤트 쿨다운 | 1000ms | 유지 |

**수정 코드**

```c
#define LIGHT_CHANGE_THRESHOLD 150U
#define LIGHT_RESET_CHANGE_THRESHOLD 75U
#define LIGHT_RESET_DURATION_MS 300U
```

**개선 내용**

- 조도 변화량 기준을 기존 50에서 150으로 상향
- 작은 센서값 변화가 이벤트로 판정되는 민감도 조정
- 초기 평균값을 기준으로 밝아짐과 어두워짐 모두 감지
- 조도 이벤트 발생 후 안정적인 복귀 조건을 적용하여 반복 감지 제어

### 작업 2. 조도 이벤트 재감지 조건 확인

**작업 대상**

- `src/event/event_detector.c`

**작업 내용**

조도 이벤트가 한 번 확정된 이후 동일한 이상 상태에서 이벤트가 반복 발생하지 않도록 재감지 조건을 확인하였다.

**동작 방식**

1. 조도 변화량이 150 이상인 상태를 연속 2회 확인
2. `EVENT_LIGHT` 이벤트 확정
3. 조도 센서의 `latched` 상태 활성화
4. 변화량이 75 미만인 상태가 300ms 지속되는지 확인
5. 안정 상태가 확인되면 래치 해제
6. 기존 1초 쿨다운 조건을 만족하면 새로운 이벤트 감지 허용

**확인 내용**

- 조도 센서의 이벤트 확정과 재감지 허용 조건이 분리되어 있음을 확인
- 순간적인 센서값 복귀만으로 재감지가 허용되지 않도록 구성
- 반복 이벤트 방지 로직은 유지하면서 임계값 변경 적용

### 작업 3. 실제 DE1-SoC 보드 재실험

**실험 환경**

- DE1-SoC FPGA 보드
- 연결된 진동·조도·소음 센서
- FPGA Monitor Program
- JTAG UART Terminal

**실험 내용**

조도 센서 임계값을 조정한 후 프로그램을 다시 실행하여 실제 조도 변화에 따른 이벤트 감지 여부를 확인하였다.

**실험 순서**

1. 프로그램 컴파일 및 FPGA 보드 실행
2. 초기 5초 동안 센서 평균값 측정
3. 준비 LED 알림 동작 후 센서 감시 시작
4. 조도 센서 주변 밝기 변화 유도
5. JTAG UART에 출력된 이벤트 플래그 확인
6. Event History와 Event Record의 기록 확인

**실제 이벤트 로그**

```text
[EVENT] 15400 ms | Flags:4 | LIGHT
[HISTORY] Saved (2/10)
[RECORD] LIGHT | BEFORE (500 samples)

[EVENT] 32030 ms | Flags:4 | LIGHT
[HISTORY] Saved (7/10)
[RECORD] LIGHT | BEFORE (500 samples)
```

**센서 측정값 예시**

```text
[SENSOR] 16060 ms | V:1232 L:292 S:57
[SENSOR] 32270 ms | V:1095 L:536 S:95
```

이벤트 발생 이후의 센서 측정값에서도 조도값 변화를 확인할 수 있었다.

**확인 결과**

- 수정된 임계값을 적용한 실험에서 조도 이벤트 발생 확인
- `Flags:4` 정상 출력
- Event History에 LIGHT 이벤트 저장 확인
- Event Record의 이벤트 전후 데이터 수집 동작 확인

## 5. 발생한 문제 및 해결

### 문제 1. 조도 센서 이벤트 임계값 조정 필요

**문제**

기존 조도 변화량 임계값 50을 실제 센서 측정 환경에 맞게 재조정할 필요가 있었다.

**원인 분석**

기존 임계값은 작은 조도 변화에도 반응할 수 있는 설정이므로, 실제 실험 환경에 적합한 감지 민감도 확인이 필요하였다.

**해결**

- `LIGHT_CHANGE_THRESHOLD`를 50에서 150으로 변경
- 초기 평균 대비 변화량을 이용하는 감지 방식 유지
- 변경된 설정으로 FPGA 보드 재실험 수행

**결과**

실제 보드에서 LIGHT 이벤트가 발생하고 `Flags:4`로 출력되는 것을 확인하였다.

### 문제 2. 조도 이벤트 반복 감지 방지 조건 확인

**문제**

조도 센서가 임계값 부근에서 변화할 경우 동일한 이상 상태가 반복 이벤트로 판정될 가능성이 있었다.

**해결**

- 조도 이벤트 발생 후 래치 유지
- 변화량 75 미만 상태가 300ms 지속되는 경우에만 잠금 해제
- 기존 1초 쿨다운 유지

**결과**

반복 감지 억제를 위한 코드 조건을 확인하였다. 실제 장시간 반복 입력에 대한 검증은 추가로 필요하다.
