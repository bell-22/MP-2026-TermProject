| 소음 | 음량 특징값이 임계값 초과 | 1000 |
| 조도 | 기준 조도값 대비 변화량 비교 | 500 |

**추가 구현 내용**

- 이벤트 확정을 위한 연속 측정 조건 적용

- 동일 이상 상태가 지속될 때 중복 감지 방지
- 이벤트 발생 후 1000ms 재감지 대기시간 적용
- 시스템 타임스탬프를 이용한 재감지 시간 관리

## 5. 발생한 문제 및 해결

### 문제 1. Mac 터미널에서 테스트 실행 파일 인식 실패

- **문제:** GCC 컴파일 후 실행 파일을 입력했을 때 `command not found` 오류 발생
- **원인:** zsh에서 현재 디렉터리의 실행 파일을 명령어 이름만으로 실행하려고 함
- **해결:** 실행 파일 앞에 `./`를 붙여 실행
- **결과:** 테스트 실행 성공

### 문제 2. 실제 DE1-SoC 보드 없이 LED/HEX 출력 검증 필요

- **문제:** Mac 환경에서는 실제 FPGA 보드의 메모리 매핑 레지스터에 접근할 수 없음
- **원인:** 하드웨어와 PC 실행 환경이 다름
- **해결:** 컴파일 옵션을 이용해 Mac 테스트용 가상 레지스터와 실제 보드용 접근 코드를 분리
- **결과:** Mac에서 LED/HEX 출력값 및 점멸 로직 검증 성공
- **추가 검증:** 실제 DE1-SoC 보드에서 물리적 LED/HEX 출력 확인 필요

### 문제 3. 실제 센서 모듈과 이벤트 모듈의 미통합

- **문제:** 이벤트 감지 코드 작성 시 실제 센서 수집 모듈과 연결되지 않은 상태
- **원인:** 팀원별 기능 병렬 개발 진행
- **해결:** 공통 `SensorSample` 구조체를 기반으로 Mock 데이터를 생성하여 독립 검증
- **결과:** 실제 센서 수집 코드 없이 감지·분류·출력 통합 테스트 완료
- **추가 검증:** 실제 센서 측정값을 전달받아 이벤트 판단 및 출력 확인 필요
