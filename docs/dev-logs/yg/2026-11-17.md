**작업 대상**

- 브레드보드(Breadboard)
- KY0138 피에조 진동센서 1개

- 1kΩ 저항 2개

- 10핀 IDC DIP PLUG 케이블 및 ADC 연결용 어댑터

**작업 목표**

실제 센서 데이터를 DE1-SoC의 ADC로 입력받기 위해 브레드보드에 진동센서와 조도센서를 직접 배치하고, 전원·접지·신호 출력 회로를 구성하여 FPGA 보드와 연결하였다.

**진행 내용**

1. 브레드보드 위쪽에 KY0138 피에조 진동센서를 배치하였다.
2. 브레드보드 아래쪽에 TEMT6000 아날로그 조도센서를 배치하였다.
3. 센서의 핀 구성을 확인하였다.
   - KY0138: `S / + / -`
   - TEMT6000: `OUT / VCC / GND`
4. 센서별 전원 및 접지 연결을 위한 점퍼선을 배치하였다.
   - 진동센서: 빨간색 (+), 주황색 (-)
   - 조도센서: 노란색 (+), 초록색 (-)
5. 브레드보드의 전원 레일을 이용하여 두 센서에 3.3V 전원과 GND를 공급하도록 구성하였다.
6. 각 센서의 출력 신호에 1kΩ 직렬 저항을 추가하였다.
7. 진동센서와 조도센서의 출력 신호가 각각 다른 ADC 채널로 전달되도록 배선하였다.
8. 10핀 IDC DIP PLUG 케이블을 이용해 브레드보드와 DE1-SoC ADC 커넥터를 연결하는 과정에서 핀 간격 및 접촉 문제를 확인하였다.
9. 브레드보드와 호환되는 ADC 연결 방식을 적용하여 어댑터 연결 문제를 해결하였다.
10. 센서 전원 및 접지 연결 상태와 ADC 입력 배선을 확인하였다.

| KY0138 진동센서 | - | GND |
| TEMT6000 조도센서 | OUT | 1kΩ 저항 → ADC_IN1 |

## 5. 발생한 문제 및 해결

### 문제 1. 복합 이벤트 표현 방식

- **문제:** 여러 센서에서 이벤트가 발생했을 때 단일 이벤트와 구분할 방법 필요
- **해결:** EVENT 비트 플래그와 OR 연산 사용
- **결과:** 복합 이벤트를 3, 5, 6, 7로 표현하는 분류 로직 구현

### 문제 2. 이벤트 중복 발생 가능성

- **문제:** 임계값을 계속 초과하는 센서에서 이벤트가 반복 발생할 가능성
- **해결:** 연속 2회 감지, 래치 및 1초 쿨다운 적용
- **결과:** 중복 이벤트를 억제하는 기본 구조 구현

### 문제 3. LED 점멸로 인한 실행 지연

- **문제:** 블로킹 방식의 LED 제어가 센서 샘플링에 영향을 줄 가능성
- **해결:** 타임스탬프를 활용한 논블로킹 LED 점멸 구현
- **결과:** 메인 루프와 병행 가능한 출력 구조 작성

### 문제 4. ADC IDC 어댑터와 브레드보드 연결 문제

**문제**

DE1-SoC ADC 커넥터와 브레드보드를 연결하기 위해 준비한 10핀 IDC DIP PLUG 어댑터의 핀 간격이 브레드보드와 일치하지 않아 직접 연결하기 어려웠다.

또한 어댑터 금속 핀이 일반 암 점퍼선 커넥터에 비해 얇아 접촉이 불안정한 문제가 발생하였다.

**원인**

- IDC 어댑터의 핀 간격과 브레드보드의 구멍 간격 불일치
- 일반 점퍼선과 어댑터 핀의 규격 차이
- 직접 삽입 시 접촉 불량 및 핀 손상 가능성

**해결**

- 어댑터를 무리하게 브레드보드에 삽입하지 않음
- 납땜 없이 연결할 수 있는 변환 방식 검토
- 브레드보드와 호환되는 ADC 연결 방식을 사용
- 기존 센서 및 저항 배치를 유지하면서 연결 작업 진행

**결과**

ADC 어댑터 연결 문제를 해결하고, 진동센서와 조도센서를 각각 ADC_IN0과 ADC_IN1에 연결하였다.

### 문제 5. 센서 출력 회로 구성 및 ADC 입력 보호 고려

**문제**

아날로그 센서의 출력 신호를 ADC에 연결할 때 센서 출력 전압과 순간적인 신호 변화로 인한 입력 불안정 가능성을 고려할 필요가 있었다.

**해결**

- 각 센서의 출력선에 1kΩ 직렬 저항 추가
- 진동센서와 조도센서에 독립적인 ADC 채널 할당
- 센서 전원과 GND 공통 연결
- 센서 출력선 및 전원 배선 상태 확인

**결과**

두 센서의 아날로그 출력 신호를 분리하여 ADC에 전달하는 회로를 구성하였다.

단, 1kΩ 직렬 저항만으로 과전압을 완전히 방지할 수 있는 것은 아니므로 실제 센서 출력 전압과 ADC 입력 범위의 적합성은 별도로 확인해야 한다.
